# رصيد الإجازات — هويست إنفينيتي

تطبيق سطح مكتب (ويندوز) لتسجيل إجازات الموظفين واحتساب أرصدتهم وفق المادة (109) من نظام العمل.

## التحميل
- **مع تثبيت:** [HoistLeaves-Setup.exe](https://github.com/Osamah077/hoist-leaves/releases/latest/download/HoistLeaves-Setup.exe)
- **بدون تثبيت:** [HoistLeaves-Portable.exe](https://github.com/Osamah077/hoist-leaves/releases/latest/download/HoistLeaves-Portable.exe)

> عند أول تشغيل قد يظهر تحذير ويندوز (SmartScreen): اضغط «مزيد من المعلومات» ثم «تشغيل على أي حال».

البيانات تُحفظ محليًا على جهاز كل مستخدم، ويمكن استيرادها من Excel/CSV وتصديرها.
